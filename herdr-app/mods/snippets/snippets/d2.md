# d2 cheat sheet

## CLI

```bash
# compile
d2 in.d2 out.svg
# redraw on save
d2 --watch in.d2 out.svg
# check it compiles
d2 validate in.d2
# reformat in place
d2 fmt in.d2
# read it as text yourself
d2 --ascii-mode extended --stdout-format ascii in.d2 -
# show it in a terminal split
~/.config/herdr/bin/diagram.ts in.d2
# list layout engines
d2 layout
# pick one for this run
d2 --layout elk in.d2 out.svg
```

## Nodes

```d2
# direction: right for request paths, down for layer stacks
direction: right
# id: Label
api: API Service
# person
user: User { shape: person }
# datastore
db: Postgres { shape: cylinder }
# broker
mq: Kafka { shape: queue }
# third party
ext: Stripe { shape: cloud }
# edge / proxy
gw: Gateway { shape: hexagon }
# decision
ok: healthy? { shape: diamond }
# start / end
begin: Start { shape: oval }
# several of these
pods: API { style.multiple: true }
```

## Edges

```d2
# directed, always labelled
a -> b: request
# same edge, written backwards
a <- b: response
# both ways
a <-> b: sync
# no direction
a -- b: peers
# dashed = async, retry, failure
a -> b: timeout { style.stroke-dash: 3 }
# coloured
a -> b: error { style.stroke: "#e06c75" }
# moving dots
a -> b: stream { style.animated: true }
# thicker
a -> b: hot path { style.stroke-width: 3 }
```

## Containers

```d2
# a container is a boundary: cluster, VPC, team, region
cluster: Kubernetes { api: API; worker: Worker; api -> worker: enqueue }
# dotted path reaches inside
gw -> cluster.api: :8080
# axis per container, overrides the parent
cluster.inner: { direction: down; a -> b }
```

## Sequence

```d2
# the only prefix that exists; actor order = first mention, message order = file order
shape: sequence_diagram
# plain message
user -> api: POST /order
# note on an actor
user."idempotency key set"
# span (activation bar)
user.t1 -> api.t1: request
# self-message
api -> api: backoff 2^n
# dashed return
db -> api: ok { style.stroke-dash: 3 }
# group; the block name is the label
retry x3: { api -> db: COMMIT }
# alt branch = a second group
gave up: { api -> user: 503 }
```

## Layout control

```d2
# placement = declaration order, edges move nothing
grid-columns: 2
# spacing in grid mode
grid-gap: 20
# pin out of the flow, root level only
legend: legend { near: top-right }
# pin beside a node, works anywhere
note: sidecar { near: cluster.api }
# pin the engine; beats diagram.ts's default of tala
vars: { d2-config: { layout-engine: elk } }
# other d2-config keys worth knowing
vars: { d2-config: { pad: 40; sketch: true } }
```

## Gotchas

```d2
# sequence diagrams ignore direction entirely
direction: right
# `a <- b` is sugar for `b -> a` — same layout, no escape from ranking
a <- b
# `--` still ranks; there is no non-constraining edge, use grid instead
a -- b
# constraint: is sql_table only, not a layout lever
sql: T { shape: sql_table; id: int { constraint: primary_key } }
# CLI flags beat vars.d2-config; diagram.ts drops the flag when you pin it
vars: { d2-config: { pad: 40 } }
# aim ~2:1 wide:tall — a long chain renders tiny, group it or draw the fan-out
chain: { a -> b -> c }
```
